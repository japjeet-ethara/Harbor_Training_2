## Reflection

- Smushing: no rule caused a failing test (the first Go build matched all 4,000 cases); the one needing the most care was rule 16 (big X), because pyfiglet's comment says `/`+`\`→`X` while its code returns `|` (and `\`+`/`→`Y`), so the port follows the code, not the comment.
- Docker: running Docker from Git Bash on Windows, a relative `-v figlet-go\solution\src:…` mount was rejected as an "invalid local volume name" and MSYS rewrote the container paths, so mounts needed `MSYS_NO_PATHCONV=1` plus an absolute path from `cygpath -wa`.
